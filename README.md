# calistenia-web-calipro

Landing page de **CaliPro**, negocio de calistenia. Bilingüe (español / inglés), pensada para móvil
y escritorio, con visor 3D de producto, códigos promocionales, guías de skills y blog.

> Estado: **arquitectura definida, sin código de aplicación todavía.**
